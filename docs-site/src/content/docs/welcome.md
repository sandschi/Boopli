Boopli turns chores into small steps and nudges you through them with the lights, speakers and phone you already have. It lives inside your Home Assistant, so there is no account, no cloud and no server.

These pages explain how to set it up and how to use each part of it. You do not have to read them in order. Use the menu on the left, or the search at the top.

## If you are new

1. [Install Boopli](/Boopli/install/) with HACS or by hand.
2. [Set it up](/Boopli/setup/). A wizard asks one question per screen, and every step can be skipped.
3. Look at [the Today screen](/Boopli/today/). It is where you do things.
4. Make your first chore in [Chores and schedules](/Boopli/chores/).

## If you want something specific

- **Nudges that climb, from a light to an alarm:** [Nudges](/Boopli/nudges/)
- **Splitting a big task into tiny steps:** [AI help](/Boopli/ai-help/), and [Ask Claude](/Boopli/ask-claude/) as an extra
- **A screen on the wall:** [Wall board](/Boopli/wall-board/)
- **Resting for a while:** [Away mode](/Boopli/away-mode/)
- **Your own automations:** [Services, events and sensors](/Boopli/automations/)
- **Something does not work:** [Troubleshooting](/Boopli/troubleshooting/)
- **What comes next:** [Roadmap](/Boopli/roadmap/)

:::note
Boopli is in early development and is not ready for daily use yet. The pages describe what is built today.
