A view for a tablet or screen on the wall. Open it with the 🖥 **Wall board** button, or put its link (`/boopli?wall`, or `/boopli?wall=desk` for a board named "desk") on the tablet's start page. A board is a grid of **tiles**. Select the pencil ✎ on the wall (or **Edit on the wall** in Settings) to change it right there, like a Home Assistant dashboard: select a tile to change its size, place and settings, add tiles, and see it as a wall, a tablet or a phone before you save. The tiles: clock, your pet in its room, what is due now (with **Done**, **On it** and **Snooze**, or **Resume nudges** after selecting **On it**), what is coming up, any Home Assistant entity (select a tile to toggle a switch, run a script, activate a scene or press a button, depending on the entity), the weather, the next calendar events, a camera image and a note. The board is a grid of square cells (16 by 9 by default, the shape of a screen) that is scaled to fit the display, so it looks the same on every screen and never scrolls. Drag a tile to move it (tiles in the way move aside), drag its corner to resize it, and use **Finer grid (cells half as big)** in the board settings for smaller steps. You can have several boards (a "wall" one and a "desk" one). While away mode is on, an **Away mode is on** banner appears at the top of the wall (and takes no space otherwise). The board keeps the screen awake where the browser allows it, and at night (outside the hours of nudging) it dims, goes black with a small clock, or stays as it is, as you choose; touching the screen wakes it for 30 seconds, and something being due keeps it awake. Every tile is its own small file, so adding your own is easy (see below).

![A wall board with the current step, the pet, the clock and what is coming up](/Boopli/img/wall.jpg)

## Make your own wall tile

A tile is one small element in `frontend/src`. Copy `wall-tile-note.ts` (the smallest one), draw what you want from `this.hass`, `this.snapshot` and `this.options`, and give it the name `wall-tile-<type>` (underscores in the type become dashes). Then import it and add one entry to the list in `wall-tiles.ts` (its name, size and the options the board settings should show), and list the same options in `TILE_OPTIONS` in `engine.py` so the integration can check them. Run `npm run build` in `frontend`.
