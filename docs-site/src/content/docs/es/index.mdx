El panel de Boopli está disponible en inglés (en), alemán (de), neerlandés (nl), francés (fr) y español (es). El panel adopta el idioma de Home Assistant. Para elegir otro idioma en este navegador, ve a **Configuración → Idioma**. La opción `?lang=xx` en la dirección tiene prioridad. Si usas Ayuda con IA o Preguntar a Claude, el servicio de IA que elijas recibe lo que compartas y puede conservarlo si funciona en la nube. Consulta [Ayuda con IA](/Boopli/es/ai-help/) para más detalles.
