Het Boopli-paneel is beschikbaar in het Engels (en), Duits (de), Nederlands (nl), Frans (fr) en Spaans (es). Het paneel volgt de taal van Home Assistant. Kies voor deze browser een andere taal via **Instellingen → Taal**. De optie `?lang=xx` in het webadres heeft voorrang. Gebruik je AI-hulp of Vraag Claude? Dan krijgt de AI-dienst die je kiest wat je deelt. Een dienst in de cloud kan die gegevens bewaren. Lees meer bij [AI-hulp](/Boopli/nl/ai-help/).
