Boopli garde ses données dans le stockage habituel de Home Assistant. Tes sauvegardes habituelles de Home Assistant les incluent donc.

## Sauvegarde

La carte **Sauvegarde** (Options en plus) te permet d’enregistrer ta configuration dans un seul fichier qui se termine par .adhd (il contient du JSON en clair). Tu peux aussi charger un fichier, par exemple sur une nouvelle installation. Choisis ce que tu veux inclure : **Paramètres**, **Tâches**, **Pièces et notes** et **Animal et historique**. Les quatre sont sélectionnés par défaut. **Importer** te montre le contenu du fichier, ce qui changerait et les appareils manquants dans cette installation. Après ta confirmation, l’importation remplace les éléments que tu as sélectionnés. Si tu importes des tâches, Boopli arrête les tâches en cours absentes de la sauvegarde. Boopli vérifie le fichier avant de modifier quoi que ce soit. La sauvegarde ne contient ni les tâches en cours, ni le mode absence, ni les fichiers image. Garde le fichier pour toi. Il peut contenir le nom de tes appareils et les notes sur tes pièces. Seuls les comptes administrateurs peuvent exporter ou importer une sauvegarde.

Si tu utilises [Aide de l’IA](/Boopli/fr/ai-help/) ou [Demander à Claude](/Boopli/fr/ask-claude/), le service d’IA choisi reçoit la tâche, tes réponses et les notes sur les pièces ou les photos que tu partages. Un fournisseur dans le cloud peut conserver ces données. Boopli supprime ses propres fichiers photo temporaires après la demande.
