Das Boopli-Panel gibt es auf Englisch (en), Deutsch (de), Niederländisch (nl), Französisch (fr) und Spanisch (es). Es übernimmt die Sprache von Home Assistant. Unter **Einstellungen → Sprache** kannst du für diesen Browser eine andere Sprache wählen. Steht `?lang=xx` in der Adresse, hat diese Einstellung Vorrang. Wenn du die KI-Hilfe oder „Claude fragen“ nutzt, erhält der gewählte KI-Dienst deine geteilten Angaben. Läuft der Dienst in der Cloud, kann er sie speichern. Mehr dazu unter [KI-Hilfe](/Boopli/de/ai-help/).
